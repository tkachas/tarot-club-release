# Как попросить агента изменить приложение

Редактору не нужно разбираться в Node.js или сервере. Откройте репозиторий в Codex или Claude Code и опишите результат для посетителя: что должно появиться, где это видно и как проверить. Снимок экрана или рисунок помогут, если речь об оформлении.

Пример запроса:

> На странице колоды добавь переключатель «Компактный вид». Когда он включён, карточки должны занимать меньше места, а подписи оставаться читаемыми на телефоне. Сохрани текущий обычный вид. Проверь оба режима в браузере и подготовь pull request со снимками экрана.

Попросите агента прочитать `AGENTS.md` и подготовить **pull request**. В описании PR должны быть простое объяснение результата, проведённые проверки и отметка, затронуты ли записи пользователей. Откройте предпросмотр или снимки, проверьте изменение и передайте ссылку владельцу для принятия и публикации.

Изменения в интерфейсе и коде сами по себе не попадают на `bimbochka.ru`: сейчас публикацию выполняет владелец после проверки PR. Не передавайте агенту пароль сайта, SSH-ключ или доступ к VDS для обычной задачи.

Для локального просмотра нужен Node.js 24. В корне репозитория выполните `node server.mjs` и откройте `http://127.0.0.1:3000`. Локальные записи сохраняются в игнорируемой папке `data/` и не должны попадать в PR. Проверка кода: `node --test test/server.test.mjs`.
